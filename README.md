# Humanity's Charter

Humanity's Charter is a public draft of an abundance framework for what comes next. It offers a concrete direction people can read, question, debate, and improve. It is not a finished constitution, a prediction, or a claim that every problem has already been solved.

The authoritative Charter text is in [`Charter/`](Charter/). The founder's purpose and starting point are in [`00-sincerity-statement.md`](00-sincerity-statement.md).

## Read and participate

Read the [public website](https://humanityscharter.org/) for governance and participation guidance. The governance process is open for discussion and development. [Discord](https://discord.gg/tBrZFgs23K) is the temporary Governance Incubator for Forum discussion and live debate. The permanent governance and voting platform has not been decided, and no binding amendment vote is open. Discord polls and chapter reactions are advisory. GitHub stores the Charter documents and their change history only: [github.com/humanityscharter/charter](https://github.com/humanityscharter/charter).
